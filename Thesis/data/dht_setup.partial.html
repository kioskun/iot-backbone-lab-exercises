DHT11 Temperature & Humidity Sensor

The DHT11 is a basic, ultra low-cost digital temperature and humidity sensor. It uses a capacitive humidity sensor and a thermistor to measure the surrounding air, and outputs a digital signal on the data pin.

Technical Specifications

Operating Voltage
3.3V - 5V
Temperature Range
0°C to 50°C
Temperature Accuracy
±2°C
Humidity Range
20% to 90% RH
Humidity Accuracy
±5% RH
Sampling Rate
1 Hz (once every second)

Connection to TTGO LoRa32

The DHT11 sensor is connected to the TTGO LoRa32 board as follows:

  • VCC → 3.3V
  • DATA → GPIO13
  • GND → GND

Implementation Notes

  • The DHT11 uses a single-wire protocol for communication
  • Internal pull-up resistor is used in this implementation
  • Readings are taken every 2.5 seconds to avoid overheating the sensor
  • The sensor can be enabled/disabled through the web interface
