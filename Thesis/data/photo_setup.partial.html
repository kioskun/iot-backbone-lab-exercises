Photoresistor with LED Control

The photoresistor (or Light Dependent Resistor - LDR) is an analog sensor that changes its resistance based on the amount of light falling on it. In this implementation, it's paired with an LED that automatically turns on in low light conditions.

Technical Specifications

Operating Voltage
3.3V - 5V
Light Resistance
5KΩ - 10KΩ (bright light)
Dark Resistance
Up to 1MΩ (darkness)
Analog Output
0-4095 (ESP32 ADC)
Response Time
~20-30ms
LED Forward Voltage
~2V (typical)

Connection to TTGO LoRa32

The photoresistor and LED are connected to the TTGO LoRa32 board as follows:

  • Photoresistor VCC → 3.3V
  • Photoresistor Signal → GPIO36 (Analog Input)
  • LED Control → GPIO17 (Digital Output)
  • GND → GND

Implementation Notes

  • The photoresistor is connected in a voltage divider configuration
  • A 220Ω current-limiting resistor is used for the LED
  • and a 10kΩ current-limiting resistor is used for the Photoresistor
  • The LED automatically turns on when light level falls below a threshold
  • Threshold is set to 2000 (out of 4095) by default
  • The sensor can be enabled/disabled through the web interface
